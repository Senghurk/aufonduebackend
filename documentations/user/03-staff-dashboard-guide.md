## Managing Assigned Issues

### Viewing Your Assignments

#### Issue List
Your assigned issues appear in a table with:
- **Issue ID**: Unique identifier
- **Title**: Brief description
- **Location**: Building and room
- **Priority**: Urgency level
- **Status**: Current state
- **Due Date**: Expected completion
- **Age**: Days since reported

#### Filtering Options
- By Status (New, In Progress, Pending)
- By Priority (High, Medium, Low)
- By Location (Building/Floor)
- By Due Date (Today, This Week, Overdue)
- By Category (Maintenance, Cleaning, etc.)

#### Sorting Options
- Newest First
- Oldest First
- Highest Priority
- Due Date
- Location

### Issue Details Page

#### Information Provided
- **Reporter Details**: Name and contact
- **Full Description**: Complete problem explanation
- **Location Details**: Exact location with directions
- **Photos/Videos**: Visual evidence
- **Timeline**: History of all actions
- **Previous Comments**: Communication thread
- **Related Issues**: Similar or connected problems

#### Available Actions
- Accept/Decline assignment
- Start working
- Update status
- Add comments
- Upload photos
- Request assistance
- Mark complete

### Accepting New Assignments

#### When You Receive a New Issue
1. Notification appears in dashboard
2. Review issue details carefully
3. Check:
   - Your expertise matches
   - You have necessary tools
   - Timeline is achievable
   - Location is accessible
4. Click "Accept Assignment"
5. Or "Request Reassignment" if unable

#### Planning Your Work
1. Review all assigned issues
2. Prioritize based on:
   - Urgency/Safety
   - Location proximity
   - Resource availability
   - Scheduled maintenance
3. Create daily task list
4. Coordinate with team if needed

## Updating Issue Status

### Status Types and When to Use

#### Available Statuses
1. **Accepted**: Confirmed assignment
2. **In Progress**: Actively working
3. **Pending Materials**: Waiting for supplies
4. **Pending Approval**: Need authorization
5. **On Hold**: Temporarily paused
6. **Needs Assistance**: Require help
7. **Resolved**: Work completed
8. **Cannot Resolve**: Unable to fix

### How to Update Status

#### Step-by-Step Process
1. Open issue from your list
2. Click "Update Status" button
3. Select new status from dropdown
4. Add mandatory status note:
   - What was done
   - What's needed next
   - Estimated completion
5. Attach photos if relevant
6. Click "Save Update"

#### Status Update Best Practices
- Update immediately when starting work
- Provide detailed notes
- Include photos of progress
- Estimate realistic timelines
- Notify if delays expected

### Completing Issues

#### Resolution Process
1. Finish all required work
2. Take "after" photos
3. Clean up work area
4. Test the fix thoroughly
5. Update status to "Resolved"
6. Add resolution details:
   - What was the problem
   - How you fixed it
   - Materials used
   - Time spent
   - Prevention suggestions
7. Upload completion photos
8. Submit resolution

#### Quality Checks
Before marking resolved, ensure:
- Problem is fully fixed
- Area is clean and safe
- No new issues created
- Reporter requirements met
- Documentation complete

## Communication Tools

### Commenting System

#### Adding Comments
1. Open issue details
2. Scroll to comments section
3. Type your message
4. Choose visibility:
   - **Public**: Reporter can see
   - **Internal**: Staff only
5. Attach files if needed
6. Click "Post Comment"

#### Comment Types
- **Status Updates**: Progress information
- **Questions**: Clarification needed
- **Responses**: Answering queries
- **Documentation**: Work details
- **Escalation**: Raising concerns

### Communicating with Reporters

#### Professional Communication
- Be polite and respectful
- Use clear, simple language
- Avoid technical jargon
- Respond promptly
- Set realistic expectations

#### Template Responses

**Starting Work:**
"I've begun working on this issue. Estimated completion: [time/date]"

**Delay Notification:**
"This repair requires special parts. New completion date: [date]"

**Need Information:**
"Could you please provide [specific information] to help resolve this?"

**Completion:**
"Issue has been resolved. Please confirm the problem is fixed."

### Team Communication

#### Requesting Help
1. Click "Request Assistance"
2. Select type of help:
   - Technical expertise
   - Additional manpower
   - Supervisor approval
   - Special equipment
3. Describe what's needed
4. Submit request

#### Collaborating on Issues
- Tag team members in comments
- Share relevant issues
- Coordinate for large tasks
- Hand over when shifting

## Daily Workflow

### Morning Routine

#### Start of Day Checklist
1. **Check New Assignments** (5 mins)
   - Review overnight issues
   - Accept/decline assignments

2. **Review Priority Queue** (5 mins)
   - Identify urgent items
   - Check for emergencies

3. **Plan Your Route** (10 mins)
   - Group by location
   - Estimate time needed
   - Prepare tools/materials

4. **Update Yesterday's Issues** (5 mins)
   - Close completed tasks
   - Update ongoing work

### During Work Hours

#### Field Work Process
1. **Before Leaving Office**
   - Gather necessary tools
   - Check material availability
   - Review issue details
   - Plan efficient route

2. **At Each Location**
   - Photograph before starting
   - Update status to "In Progress"
   - Complete the work
   - Document with photos
   - Clean up area
   - Update status when done

3. **Between Locations**
   - Check for new urgent issues
   - Respond to comments
   - Update completion times

### End of Day

#### Closing Tasks
1. **Update All Issues** (10 mins)
   - Close completed work
   - Add progress notes
   - Flag tomorrow's priorities

2. **Respond to Messages** (10 mins)
   - Answer reporter questions
   - Internal team communication

3. **Prepare for Tomorrow** (5 mins)
   - Review next day's schedule
   - Note materials needed
   - Submit supply requests

## Troubleshooting

### Common Problems

#### Cannot Access System
- Check internet connection
- Clear browser cache
- Try different browser
- Reset password
- Contact IT support

#### Issue Not Appearing
- Refresh browser
- Check filters
- Verify assignment
- Look in different status
- Ask administrator

#### Cannot Upload Photos
- Check file size (<5MB)
- Verify file format (JPG/PNG)
- Check internet speed
- Try smaller image
- Use mobile browser

#### Status Won't Update
- Check required fields
- Add status note
- Verify permissions
- Try again later
- Report to admin
