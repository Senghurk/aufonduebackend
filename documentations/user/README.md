## 🎯 Quick Start

### For Mobile App Users
1. Download AU Fondue app from Play Store
2. Login with Microsoft account (@au.edu email)
3. Report issues with photos/videos
4. Track status in "My Reports"

### For Administrators
1. Access dashboard at your provided URL
2. Login with admin credentials
3. View and manage reported issues
4. Assign issues to staff members
5. Generate reports as needed

### For Staff Members
1. Access dashboard at your provided URL
2. Login with staff credentials
3. View your assigned issues
4. Update status and add remarks
5. Mark issues as resolved when complete

## 🔑 System Access

### Mobile App
- **Login**: Microsoft account with @au.edu email
- **Platform**: Android (Google Play Store)

### Web Dashboard
- **Admin/Staff Login**: Firebase Authentication
- **Access**: Via provided URL from system administrator

## 📋 Key Features by Role

### Mobile App Users
- Report facility issues with description
- Attach photos/videos (up to 5 files)
- Select issue category and location
- Track issue status
- View submission history
- Receive push notifications

### Administrators
- View all reported issues
- Assign issues to staff members
- Update issue status
- Generate reports (daily, weekly, monthly)
- Manage staff accounts
- View system statistics

### Staff Members
- View assigned issues
- Update issue status
- Add remarks and progress notes
- View daily assignments
- Mark issues as resolved

## 📊 Issue Status Flow

```
Reported → Assigned → In Progress → Resolved
```

Additional statuses:
- **Pending** - Awaiting action
- **On Hold** - Temporarily paused
- **Cancelled** - Will not be resolved

## ❓ Common Questions

**Q: How do I report an issue?**
A: Use the AU Fondue mobile app to submit a report with photos

**Q: How long does resolution take?**
A: Typically 1-5 days depending on issue complexity

**Q: Who can access the web dashboard?**
A: Only authorized administrators and staff members

**Q: Can I edit a submitted report?**
A: No, but you can add comments to provide additional information
